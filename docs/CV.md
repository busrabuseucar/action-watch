**ActionWatch — GitHub Actions Dashboard**  
Personal project · AI-assisted development  
TypeScript, GitHub REST API, async JavaScript, Node.js, GitHub Actions

- Read-only MVP for inspecting recent public-repository workflow runs and job steps, with result, workflow and branch filters.
- Validated API responses, request cancellation, stale-response protection, caching, timeout and rate-limit handling, with a clearly labeled sample mode.
- 28 automated tests for metrics and API behavior, strict TypeScript checking and a GitHub Actions verification workflow.

Bu bir üretim operasyon sistemi veya ticari müşteri deneyimi değildir. Kendi katkını yalnızca gerçekten geliştirdiğin, incelediğin ve doğruladığın işler üzerinden anlat.
